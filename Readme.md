1) Проект создан для практики в Go. На его примере отрабатываются:
2) ввод данных с клавиатуры (fmt.Scan);
3) работа с типами string и float64;
4) функции, которые возвращают несколько значений;
5) циклы for с операторами continue и break;
6) условия if и логические операторы &&, ||;
7) вложенные конструкции switch;
8) обработка ошибок (err != nil).
9) Возможности:
    1) Конвертация между тремя валютами: USD, EUR, RUB (все шесть направлений).
    2) Пошаговый ввод: исходная валюта, затем сумма, затем целевая валюта.
    3) Проверка каждого шага: при неверном вводе программа сообщает об ошибке и просит ввести данные заново, а не завершается.
    4) Защита от конвертации валюты в саму себя: в подсказке при вводе целевой валюты показывается, какую валюту выбирать нельзя.
    5) Работает с дробными числами (тип float64).
10) Требования:
    1) Установленный язык Go (рекомендуется версия 1.20 или новее): https://go.dev/dl/
    2) Терминал (командная строка), например встроенный терминал в VS Code.
    3) Внешние библиотеки не нужны, используется только стандартный пакет fmt.
